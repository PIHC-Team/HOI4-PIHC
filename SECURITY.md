# Security policy

## Supported source

Only the current `master` branch receives security and data-safety fixes. The
`legacy` branch is preserved for historical PIHC2 reference.

## Reporting privately

Do not open a public issue for leaked credentials, malicious files, unsafe
build behavior, or another vulnerability that could put contributors at risk.
Use GitHub's **Security → Report a vulnerability** flow when it is available,
or email `magolorcz@gmail.com` with the subject `[PIHC3 Security]`. Include the
affected revision, reproduction steps, impact, and any safe diagnostic
evidence.

For ordinary crashes, build diagnostics, gameplay defects, and content errors,
use the public bug-report template instead.
