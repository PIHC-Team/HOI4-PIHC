Las Pegasus Lab Research Project Application: Code 546. <=Square Root=> 
[zh.@desc]
代号546.「平方根」：旨在开发一种由独角兽魔法驱动的自动计算工具。原型：根据自由小马利亚获得的情报，人类世界存在一种名为“计算机”的工具，科学计算能力相当于0.83暮（暮光闪闪，计算能力单位，通过一秒钟能够计算的546平方根数量来测量），魔法芯片预计可以将该工具的计算能力提升至1.4暮。
[en.@desc]
Code 546. <=Square Root=> : Aims to develop an automatic computation tool powered by unicorn’s magic. Prototype: A tool named “Computer” accordin to information collected from human world from the Free Equestria. Its computation power is around 0.83 TW (short for Twilight Sparkle, unit of computation, measured by the number of 546-square-root calculation time per second), while introducing magic could possibly improve that to 1.4 TW.
