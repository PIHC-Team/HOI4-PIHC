# 高堡奇驹模组

“我们曾经拥有魔法，和友谊，但现在，我们失去了一切。”
假若，和煦光流、邪茧和提雷克取得了终末之战的胜利……那会是一个怎样的世界？
在这样一个架空世界中，世界线从G4第9季第24集开始发生了变动……在决定小马利亚命运的终末之战中，没有来自各个地区的小马和各个其他种族的帮助，M6在战斗中落败。999年，“三巨头”——和煦光流、邪茧女王和提雷克大王组成的反派军团，取得了终末之战的胜利。1001年，“三巨头”在坎特洛特签署了瓜分小马利亚的协议：和煦光流为小马国的正统统治者，自封为“友谊女皇”，使用天角兽的绝对力量和充满蛊惑力的花言巧语，在小马利亚的废墟之上，建立了一个松散的分封制国家；在武力征服幻形灵王国后，邪茧女王肃清了所有反对者，重新恢复了她不容置疑的、至高无上的领导地位，并将整个幻形灵族群变回了原来的未化茧状态；提雷克大王则对权力并不痴迷，他更加痴迷于力量——他使用格罗迦之铃取走了小马利亚一半的魔法，回到了他的半人马家乡，并顺路奴役了周边的所有生物。M6和两位前公主被关押在塔尔塔洛斯监狱——那个曾经关押提雷克与和煦的地方。而且，她们是被分开关押的。无序、星光等小马虽然失去了魔法，但在终末之战的混乱中逃脱，他们联合不满于“三巨头”统治的小马们，在小马利亚各地组织着抵抗力量；大多数生物则接受了他们的失败，和他们悲惨的命运……

## 模组特性

- **故事导向的小马世界**：故事忠于《小马宝莉》正剧，没有原创角色和脱离设定角色（大概）

- **黑色幽默**：到处都是政治讽刺与经典引用

- **全新科技**：从木制近战兵器到魔法的巨大机器

- **镜像传送门**：派遣你的部队超越光速

- **赌徒派对**：大量的随机事件和决议

- **冰雪行军**：在寒冷的全球气候中和各种怪物作战

- **魔法对轰**：具有特殊技能的特种部队

- **背包系统**：像RPG游戏一样的钢4体验

- **原创音乐**: 高堡奇驹专辑与电台音乐

- **持续更新**：大量内容将持续更新

- **自动开发工具**：本模组是通过自动开发工具HOI4DEV生成的（关于该工具的详细信息在下面）

**支持语言**:

3. 请各位玩家注意检查政治平衡。

## 非Steam安装

### Windows

（未经测试：可能会随机崩溃）

将模组文件夹和描述文件移动到`"C:/Users/<YOUR_USER_NAME>/Documents/Paradox Interactive/Hearts of Iron IV/mod"`。文件结构：
```
Hearts of Iron IV/
  mod/
	PIHC_dev/
	PIHC_dev.mod
```

用文本编辑器打开`PIHC_dev.mod`，在最后一行替换`path`：

```
...
path = "C:/Users/<YOUR_USER_NAME>/Documents/Paradox Interactive/Hearts of Iron IV/mod/PIHC_dev"
```

然后启动HOI4启动器重新加载已安装的模组。

## 关于HOI4DEV

[url=https://github.com/Magolor/hoi4dev]Github链接[/url]

HOI4DEV是由本模组的作者Talirian创建的一个Python库。HOI4DEV是一个用于自动开发HOI4 MOD的包，它允许MOD开发者比以往更快地构建MOD。

有用的功能包括CCL（Clausewitz脚本语言）到JSON转换器，JSON到CCL转换器，DDS图像编辑，自动国策定位，快速角色创建，快速事件创建，快速技术创建，自动多语言本地化等。

目前，HOI4DEV包没有GUI。如果您是一个对HOI4DEV感兴趣的Python程序员或一个普通的MOD开发者，希望帮助开发HOI4DEV或HOI4DEV GUI，请随时联系Talirian。
