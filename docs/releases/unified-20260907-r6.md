# Unified PIHC3 r6 — temperature GUI correction

The temperature panel restores its legacy lower-right position (y=−362 instead of −480). The mercury now uses outdoor temperature with y=129−4T; the clipping container starts at y=40 and retains a 438-pixel clipping height. r5 incorrectly scaled the sprite position a second time and shifted the clip origin, making −1 °C appear near −13 °C. Endpoint-only checks failed to reveal this.

A clean native HoI4 1.19.2 launch verified −30, −10, +10 and +30 °C at labeled ticks, plus the +42 °C upper endpoint. The reported case logged outdoor −1, indoor 4, mercury_y 133. The indoor dial covers the tip near zero. The original lower attachment is restored; full visibility at all resolutions was not verified because the small test window also clips the legacy state view.

Validation: 38 temperature tests passed; full build produced zero diagnostics. Only two game files changed, preserving all r5 gameplay and localization integrations. Existing saves refresh cached mercury positions on their next monthly temperature update.
