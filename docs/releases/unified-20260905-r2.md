## Reproduce and verify

Use Python 3.12 and `requirements-build.txt`, which pins ParaDev commit `26e6ad5858e0fab9970cf270b9d34031d8e0699b` and its dependencies:

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements-build.txt
PARADEV_HOI4_MOD_ROOT="$PWD/dist/mod" .venv/bin/paradev build . \
  --emit-artifacts --full-rebuild --no-sync-launcher-descriptor --summary --json
python3 scripts/verify_release.py dist/mod/PIHC3
```

The default verifier uses `unified-20260905-r2-files.json`. For historical r1 output, explicitly pass `--manifest docs/releases/unified-20260905-files.json`. The compiled package contains ordinary game files and needs neither a source checkout nor a compiler.
