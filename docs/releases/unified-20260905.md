This release establishes one ParaDev-native source and one independently playable compiled mod. The source is `PIHC-Team/HOI4-PIHC` on `master`; the compiled distribution is `Magolor/HOI4-PIHC-Compiled` on `main`. The matching release tag is `unified-20260905-r1`.

## Reconciled content

- Rock Farm adds 14 focuses and 10 events, plus trade and consolidation decisions, six ideas, a Rockville flag, character-cost changes, and related C12/C14 diplomacy. Definitions and localization live in their native semantic source owners.
- C67 includes its country, character, ideas, unit history, flags, initial diplomacy, and nine transferred states. The user explicitly selected inclusion. Reuse existing PIHC art for its two ideas because the donor did not provide icon assets.
- C08 imports the revised “By Your Side” parliament interaction, four additional parliament decisions, the East Route startup requirement change, and the removal of the self-retriggering event option. The donor-retired automatic East Route mission is explicitly inactive in source.
- Import the division designer's black numeric/Chinese labels and accompanying layout.
- Repair the donor's malformed C67 localization line, preserve intentional empty descriptions, and provide English country labels. One conflicting existing Chinese C12 event description is retained instead of replacing the newer PIHC3 wording.

## Changes deliberately not imported

The bugfix snapshot predates some source repairs. Retain the current mod title, descriptor settings, workshop identifier, and thumbnail. Retain quoted intelligence-agency names, deduplicated doctrine modifiers, current HQ balance, validated adjacency data, modern game-version support, and current canonical identifiers. Do not reintroduce retired parallel doctrine/achievement definitions, old filenames for migrated states/regions, superseded identifier aliases, or redundant PNG/render-conversion copies.

The Rock Farm snapshots also contain older game-version UI, doctrine, faction, technology and equipment data, and older narrative text outside the expansion. These do not replace the current PIHC3 implementations. This is a reconciled PIHC3 release, not an overlay of entire snapshot directories.

## Build and verify

Python 3.12 is recommended. `requirements-build.txt` pins the ParaDev compiler revision; that compiler pins HeavenBase 0.1.2.2 and Pillow 12.3.0. Build in a dedicated output location:

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements-build.txt
PARADEV_HOI4_MOD_ROOT="$PWD/dist/mod" .venv/bin/paradev build . \
  --emit-artifacts --full-rebuild --no-sync-launcher-descriptor --summary --json
python3 scripts/verify_release.py dist/mod/PIHC3
```

The verifier requires only Python's standard library. It checks every compiled game file against `unified-20260905-files.json` and rejects extra game files. Generated ParaDev publication metadata and external launcher descriptors are not part of the game-file digest.

The compiled release contains ordinary files, no source links and no build-time dependency. Players need only Hearts of Iron IV and the compiled package. Follow the compiled repository's installation instructions.

## Validation boundary

A clean combined build passes with zero diagnostics. The startup-contract audit and source/output checksum verification are release gates. All C12 focus definitions also match the Rock Farm compiled snapshot semantically. Reference auditing compares the baseline and unified output: the expansion adds no unresolved texture paths, broken focus references, duplicate focus IDs, or duplicate event IDs. Its new focus shine references resolve to the existing base-game texture.

The broad ParaDev suite completed 2,614 tests successfully with 9 platform skips and 17 failures before remaining workers were interrupted after lock waits. Several failures assert the previous 738-focus/67-country inventory or exact old source digests. A separate untouched-source check reproduced four README/layout expectation failures. Separate serial checks confirmed that the remaining inspected runtime/state-lore/portrait assertions fail only on the new country, localization-artifact, and character counts. The full toolkit suite is therefore not a green release gate; the independent clean build, startup checks, and exact game-file verification are the evidence for this compiled release.

These checks do not replace an in-game campaign playtest. No campaign or save-game compatibility claim is made.

Source checkout line endings are pinned to LF. Clean clones normalize 61 font-related text files that had CRLF in the original working copy; the final manifest uses the clean-checkout bytes. The final release tag is `unified-20260905-r1`; the initial un-suffixed tag is superseded.
