# PIHC3 r5 — stable monthly temperature system

This release retains the [r4 donor reconciliation](unified-20260906-r4.md) and fixes temperature scheduling, arithmetic and display. The [temperature-system reference](../temperature-system.md) explains the mechanics and execution order.

The generic monthly hook was recalculating the entire world for multiple country callbacks. A global calendar key now permits one world update per month; seasons are derived from the actual engine date instead of incrementing a drifting counter. Indoor heat and comfort are evaluated once per state, tower-neighbor heat is distributed from towers only, and population-weighted arithmetic is scaled before multiplication.

The mercury bar now uses a variable-driven y coordinate with clipping and the original single texture, replacing an 82-frame strip. One refresh revision updates the GUI. The panel is raised to keep the thermometer visible in the tested window. Self-heating no longer charges all government heating costs, and wood shortage fallback no longer incorrectly requires a simultaneous coal shortage.

The compiled mod remains standalone. Only temperature runtime files change from r4; the unused mercury strip is removed. Chinese/English separation, state names, Rock Farm, C67, fonts, event scrollbars and the revised Mane Six story remain intact.

Final native verification: December 1002 → March 22, 1003 produced exactly three scheduled updates (revision 1 → 4), with the season correctly at month 3. The final calculation completed another 120 forced updates (revision 4 → 124), self-heating logged zero coal/wood/factory costs, and every state had an initialized outdoor temperature. No temperature-specific errors were recorded. The guarded test exited normally through the game menu; an earlier pre-guard test stalled after a direct quit/hot-reload session and required force quit.

A final clean launch verified the scaled mercury at +42 °C and −50 °C: the full bar and the bottom cap remain inside the tube. Thirty-three targeted temperature tests pass, the generated build has zero diagnostics, and all 41,732 bilingual dependency keys resolve. The manifest contains 35,558 standalone game files.
