# PIHC3 r4 — complete dependency reconciliation

Release: `unified-20260906-r4`.

This release keeps the standalone r3 mod and regenerates it from the canonical ParaDev source after an all-input reconciliation pass. Source inventories and explicit compatibility exclusions are recorded in `unified-20260906-r4-integration.json`.

## Changes

The independent integration gate follows all `tooltip`, `custom_effect_tooltip`, `custom_modifier_tooltip` and `custom_cost_text` references in compiled scripts. It resolves English and Simplified Chinese separately with the installed game as fallback, requires the direct state/victory-point table paths in three languages, rejects their old duplicate paths, and checks the country-selection widgets the engine requests. It checks dependencies rather than country-name prefixes or a release checksum alone. Run it before publishing any subsequent build:

```bash
python3 scripts/check_integration.py /path/to/PIHC3 --reference /path/to/Hearts\ of\ Iron\ IV --json
python3 scripts/verify_release.py /path/to/PIHC3
```

Restored the C15 parliament tooltip supporting the imported C08 decisions, corrected obsolete C02/C03/C04/C44/technology tooltip references, added missing C03/C04/C08/C12 descriptions and completed the Rock Farm English tooltip keys. New explanatory text describes existing triggers/events; it does not add invented gameplay effects. C00 now has the donor's Unclaimed Wasteland / 无主荒地 label. Chinese and English remain separate.

Restored all three country-selection `new_content` widgets and corrected tests that previously asserted their absence. State names retain the direct-file override repaired in r3.

The resources ZIP contained changes beyond country-specific Rock Farm files. This pass also integrates resource-development AI weights and C12 political-power refunds, increased mineral exploration yield, War Radio balance, WETM trade/AI changes, C54 magic-academy balance and AI priorities, the Diamond Wave trait, and the C08 resistance modifiers. The donor's forestry refund is moved to country scope; bond purchase availability now matches the 1,800-bond price and deduction; new AI bond comparisons use `check_variable` instead of display-format expressions.

The C08 bugfix gameplay, C67 and its nine state transfers, Rock Farm focus/event expansion, equipment readability, long-event scrollbars, approved missing/unknown M6 story and replacement art remain included. Legacy vanilla-version formats, obsolete identifiers, shared placeholder-character recruitment and the donor's incorrect branding remain explicitly excluded. The mod does not require any donor folder or source checkout to run.
