# Unified PIHC3 r8 — localization newline escape correction

r8 fixes the localization writer and PIHC3 reconciliation extension so authored HoI4 escape sequences such as \n and \t are preserved exactly once. Previously, every backslash was escaped again, causing 70 generated localization files to contain \\n or \\t, which HoI4 displayed literally.

The fix preserves valid existing HoI4 escapes, converts real line breaks to engine escapes, and continues escaping literal backslashes and quotes. Two replacement source entries that already contained doubled escapes were normalized. The build is pinned to ParaDev compiler commit be03ab849604d5c33ac58cee673aaf9bee9b5145.

Validation: clean build with zero diagnostics, 70 corrected files, zero remaining doubled newline/tab escapes, 41,732 bilingual keys with zero integration errors, startup contracts passed, and localization regression tests passed.
