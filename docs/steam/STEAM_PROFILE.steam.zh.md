[h1]高堡奇驹模组[/h1]

“我们曾经拥有魔法，和友谊，但现在，我们失去了一切。”
假若，和煦光流、邪茧和提雷克取得了终末之战的胜利……那会是一个怎样的世界？
在这样一个架空世界中，世界线从G4第9季第24集开始发生了变动……在决定小马利亚命运的终末之战中，没有来自各个地区的小马和各个其他种族的帮助，M6在战斗中落败。999年，“三巨头”——和煦光流、邪茧女王和提雷克大王组成的反派军团，取得了终末之战的胜利。1001年，“三巨头”在坎特洛特签署了瓜分小马利亚的协议：和煦光流为小马国的正统统治者，自封为“友谊女皇”，使用天角兽的绝对力量和充满蛊惑力的花言巧语，在小马利亚的废墟之上，建立了一个松散的分封制国家；在武力征服幻形灵王国后，邪茧女王肃清了所有反对者，重新恢复了她不容置疑的、至高无上的领导地位，并将整个幻形灵族群变回了原来的未化茧状态；提雷克大王则对权力并不痴迷，他更加痴迷于力量——他使用格罗迦之铃取走了小马利亚一半的魔法，回到了他的半人马家乡，并顺路奴役了周边的所有生物。M6和两位前公主被关押在塔尔塔洛斯监狱——那个曾经关押提雷克与和煦的地方。而且，她们是被分开关押的。无序、星光等小马虽然失去了魔法，但在终末之战的混乱中逃脱，他们联合不满于“三巨头”统治的小马们，在小马利亚各地组织着抵抗力量；大多数生物则接受了他们的失败，和他们悲惨的命运……

[h2]模组特性[/h2]

[list]
    [*][b]故事导向的小马世界[/b]：故事忠于《小马宝莉》正剧，没有原创角色和脱离设定角色（大概）
    [*][b]黑色幽默[/b]：到处都是政治讽刺与经典引用
    [*][b]全新科技[/b]：从木制近战兵器到魔法的巨大机器
    [*][b]镜像传送门[/b]：派遣你的部队超越光速
    [*][b]赌徒派对[/b]：大量的随机事件和决议
    [*][b]冰雪行军[/b]：在寒冷的全球气候中和各种怪物作战
    [*][b]魔法对轰[/b]：具有特殊技能的特种部队
    [*][b]背包系统[/b]：像RPG游戏一样的钢4体验
    [*][b]原创音乐[/b]: 高堡奇驹专辑与电台音乐
    [*][b]持续更新[/b]：大量内容将持续更新
    [*][b]ParaDev 创作[/b]：本模组通过 ParaDev 桌面 GUI 和 Python SDK，从模块化、易读的源码编译而成
[/list]
